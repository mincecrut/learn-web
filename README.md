# Нур — исламский сайт

Статический сайт на чистых HTML, CSS и JavaScript (без фреймворков и сборки). Работает на GitHub Pages.

## Разделы

- Столпы ислама
- Коран: 114 сур, поиск, чтение аятов на арабском с русским переводом
- Время намаза для городов Казахстана, России и других стран
- Дуа на каждый день
- Контакты (ссылка на чат в Telegram для вопросов и предложений)

## Файлы

| Файл | Назначение |
| --- | --- |
| `index.html`, `style.css`, `script.js` | сам сайт |
| `quran/` | арабский текст Корана и русский перевод, по одному файлу на суру |
| `favicon.svg`, `404.html`, `robots.txt` | значок, страница ошибки, настройки для поисковиков |

## Что нужно сделать перед публикацией

1. **Проверьте тексты.** Арабские тексты дуа в `index.html` сверьте с проверенным изданием.
2. **Open Graph.** После публикации добавьте в `<head>` теги `og:url` и `og:image` с полными адресами вашего сайта.

## Запуск на компьютере

Откройте папку проекта в терминале и запустите локальный сервер (прямое открытие `index.html` из проводника не подойдёт: браузер блокирует загрузку файлов):

```
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий и загрузите в него все файлы в корень (вместе с папкой `quran/`).
2. Откройте **Settings → Pages**, в разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
3. Через 1–2 минуты сайт будет доступен по адресу `https://ваш-логин.github.io/название-репозитория/`.

Если сайт опубликован как личный (репозиторий `ваш-логин.github.io`), в `404.html` поменяйте `isUserSite` на `true`.

## Настройка

- **Города намаза:** массив `cities` в начале `script.js`. Города Казахстана берутся из API Namaztimes (нужен `ntId`), остальные считает Aladhan по координатам.
- **Области Казахстана:** массив `namaztimesRegions` в `script.js`. Добавьте `slug` области из списка городов на Namaztimes.kz.
- **Цвета и тема:** переменные в начале `style.css`.
- **Шрифты:** подключены с Google Fonts (Amiri, Lora, Source Sans 3). Для полной независимости от внешних сервисов их можно скачать в папку `fonts/` и подключить через `@font-face`.
